# Proposed additions to the RA2 1.001 matching guide

## Workflow

- **W1, extend.** Keep a whole-donor build and a native sibling build as separate baselines. For each ported block, record the RA2 instruction that justifies the donor expression and the RA2-specific edits it needs. Can_Repair_Bridge (0x166110) reached 0/2,112 only after adapting tile comparisons, directional cursors and the wood orientation branch together.
- **W3, extend.** Search for the smallest matched sibling that performs the disputed operation. Record its RVA or symbol, callee sequence and one incompatible alternative before adapting it. Quaternion::Make_Closest (0x219e20) recovered its five reference calls with quaternion division and indexed component products; expanding the matched division operator at both callers grew the object to 528 bytes.
- **W6.** For a stalled body with uncertain call boundaries, make one independent reconstruction from the disassembly, verified callees and a sibling before reading the parked source. Save the draft and compare its frame, calls and first divergence with the donor and parked builds. The blind Make_Closest (0x219e20) draft still overshot by 64 bytes, which directed comparison to the operator boundaries.
- **W7.** For any newly solved recurring pattern, add the witness, failed hypothesis, scope of the successful edit and tested controls to the guide at batch close. Update_Cell_Subzones (0x163130) illustrates the distinction between the first donor lead in batch 47 and the accepted RA2 result in batch 49.

## Compiler rules

- **C19.** When two scalars compete for order against an unrelated load, look for an aggregate initialised at declaration. Compare its field order with a matched user before sweeping declaration counts. Draw_Pixel_Effects (0x29d4c0) provides the sparkle-position and buffer-pitch example.
- **C20.** If the target repeats a test or store along different paths, trace both uses back to one flag or shared statement. Check an equivalent matched sibling for the guard order, then compare the compiler's duplicated tails. MechLocomotionClass::Movement_AI (0x18e7a0) uses the cell-change flag twice and shares the IsNewNavCom clear.
- **C21.** If arithmetic matches except for register choice, inspect how the operand is obtained, including conversion operators and the exposed result type. Place_Veins (0x7a900) uses Random2Class conversion for the overlay offset and a FACING_90 neighbour step.

## Dead ends

- **D5, extend.** Reopen a coupled residue when a newly matched donor, callee or cross-version instruction supports a different source structure. Name the predicted change, replay it against a fixed baseline and retain W4 binding checks. Can_Repair_Bridge (0x166110) reached zero masked differences with 61 bindings open; Send_Statistics_Packet (0x28e3f0) retained one byte after testing its donor's option-flag approach.
