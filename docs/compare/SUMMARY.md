| What our searches miss | Where the distinction matters | Concrete change |
|---|---|---|
| An accessor or operator introduces a different inline call chain even when its arithmetic looks equivalent. | Draw_Extras takes the matrix translation as a vector. Place_Veins selects the random generator's conversion operator. | For the first differing expression, enumerate the real member, conversion and operator overloads present in the reference headers. | The first differing instruction in a caller can originate in another function. | TeamClass::AI inherits a branch from its inlined mission routine. Nearing_Target and Magnitude_At_Least form a caller/comparator pair. | When caller bodies agree, compare direct callees and emitted symbols before generating further caller edits. Keep a sibling that uses the shared header as a control. |
| Two equivalent-looking locals can preserve different identities through a loop or call. | IonBlastClass::AI keeps an ObjectClass pointer for traversal and a FootClass pointer for derived operations. The planning renderers keep a center point separately from the rolling source. | Generate variants that split a live value at a cast, conversion or copy. Check which value must survive the call or the next loop iteration, and vary those uses together. |
| A complete branch arrangement can matter even when a single copied statement gives no gain. | Is_Owner_Tested_Control repeats the ID test on separate return paths. The shroud helper in TeamClass::AI repeats the target-selection calls in two arms. | Add paired split/merge variants to the branch generator. Try the complete donor branch before scoring individual edits, then remove one change at a time from the best form. |
| The loop's stored induction variable may differ from the visible array index. | IonBlastClass::One_Time derives its descending offset from an ascending counter. | A whole donor body can still need a version-specific expression or dependency. | Update_Cell_Subzones uses native zone/connection access while retaining community traversal. | A failed one-edit trial can discard a change that is essential in the winning combination. Conversely, a prominent donor edit may be irrelevant to the match. | In Movement_AI, hunk 9 gives no gain by itself but reverting it from the winner costs 853 differing bytes. For Planning_Connect_Selection the typed call alone removes 42 differences, while the predicate and count-accessor hunks leave the prior score unchanged individually. | Run both directions against fixed controls: add each hunk to the failed body and remove it from the passing body. If those answers disagree, keep the hunk for pairwise tests instead of discarding it on the greedy score. |

Each rule proposes a bounded experiment. Keep the passing body as a positive control, reconstruct the recorded failed body as a negative control when it survives, and record compiler, headers, object size, masked differences, and unresolved bindings. A byte-identical object after a neutral ablation proves neutrality only in that build context.
