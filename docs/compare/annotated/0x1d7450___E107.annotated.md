All three supplied diff sections lack a function body. VC6 emits this exit-time cleanup routine for the static control dictionary. The relevant source hunk is the end of the matched ownrdraw.cpp translation unit in history_before_after.zip.

**DECISIVE**, isolated as a single addition. Before, the general template in dict.h ran `clear()` and then `delete[](table)`. The port adds an explicit inline specialization for `Dictionary<unsigned int, OwnerDraw::WinData>::~Dictionary()` at the end of ownrdraw.cpp, with its own small resize predicate. Its body owns the entire traversal. For each bucket it saves the old node, advances via `node->hashNext`, deletes the old node and zeros the bucket. After zeroing the entry count, it shrinks while above the minimum size and unlocked, then deletes the table. The generic clear already performed this traversal. The material change is its inline and instantiation boundary and the expression used to test the resize lock.

The old threshold test used `keepSize==FALSE`. The specialization calls `Can_Resize_Own_Controls(keepSize)`, a TU-local inline function taking a char and returning its negation. The winning source credits the donor's member `Can_Resize` and explicitly labels the free-function adaptation as inferred. Variable renaming and the Node typedef express the same types. No individual necessity is claimed for these spellings.
