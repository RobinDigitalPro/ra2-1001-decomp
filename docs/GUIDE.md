# RA2 1.001 matching guide

For near misses and gaps compiled with VC6 build 8168. Addresses are RVAs in the 1.001 image. Each rule has a corresponding entry in GUIDE_SOURCES.md.

## Workflow

- **W1** Port the whole matched community body first when sizes agree closely. Adapt names, compile, then inspect the remaining differences. Repair_Bridge (0x152ef0) closed on the first port after a 1,813-byte miss.

- **W2** For a gap, build the skeleton from the object’s section order and anchored neighbours. Work one recognizable chunk at a time: compare frame allocation, switch dispatch, calls and shared tails before tuning expressions. In Default_Dialog_Proc (0x1f77c0), a 0x200 frame excess identified the inlined WinData path.

- **W3** Triangulate 1.001, your object and 1.006. Bound the 1.006 search by ordered matched neighbours, compare masked instructions, then inspect the upstream body, nearby inlines and defines. IonBlastClass::AI (0x120880) reached identical bytes with one binding still open.

- **W4** When bytes agree, verify relocation targets and object ownership before claiming. The ZeroRect initializer (0x169ed0) passed under two names; object order must establish its owner.

- **W5** Stop when the ledger records zero retries. Record the input, best and delivered differences, last forms, blocker, no-gain count and evidence; reopen on a new method. Place_Veins (0x7a900) reached three no-gain rounds.

## Compiler rules

- **C1** For a missing /Ob2 expansion, locate the cut with a scratch probe, then inspect the bodies and nesting of real callees. TeamClass::AI (0x2ad120) recovered the missing unit inside TMission_GOTO_SHROUD by giving its two branches separate calls. The general caller-budget formula remains open.

- **C2** For a function-wide register swap, trace each value’s live range through calls and high-pressure blocks. Test a real intermediate that changes a use. Per_Cell_Process (0xfffa0) needed the named result of Techno_Type_Class(). The compiler’s priority order is measured; source-to-web mapping is partial.

- **C3** When a declaration changes distant bytes, calibrate the translation unit (TU) at the actual insertion point. Period 64 reproduced all eight sampled entry-point pairs. Use the sweep to locate a natural declaration; Print_CRCs (0x221b90) also has a narrow good window.

- **C4** Check where a shared declaration or inline body first becomes visible. Even a body-only edit that adds named locals can disturb later allocations. Recheck SelectClass::Action (0x2761a0) after changing such a header.

- **C5** For a large shift with an unchanged exception-handler ID, compare first occurrences of strings. Moving one literal across three tags reproduced the 486-position shift in WinMain (0x283970).

- **C6** If frame slots change across otherwise equivalent builds, compare the lowest numbered label. It predicted Trackbar_Proc (0x1f30a0) stack layout in 171 of 171 held-out builds.

- **C7** Map each frame slot to its occupants. Memory locals occupy their enclosing block, expression temporaries last a statement, and scalar spills follow liveness. Narrow the block if a local needs a dead argument slot. In Print_CRCs (0x221b90), loop-local pointers recovered the slot layout.

- **C8** If scalar slots move around an aligned double, inspect slot ordering and alignment before adding a variable. A four-byte hole may mean an existing scalar crossed the double. See TechnoClass::Fire_At (0x2bfe50).

- **C9** When x87 operations match but loads move around a call, restore the type conversion visible in the constants. BulletClass::Unlimbo (0x612e0) matched with a DirType constructed from radians followed by As_Radian().

- **C10** Decode the jump table to case targets before reordering a switch. If dispatch already matches, inspect code inside each arm. TeamClass::AI (0x2ad120) had identical tables and a register difference in an inlined helper.

- **C11** For a missing leading jump-table entry, try giving that case its own return. Quarry_To_Threat (0x619c70) started its table at case 2 when case 1 shared the default via break.

- **C12** When a loop’s register sequence or frame differs, recover the walked value, its type and the update site together. Repair_Bridge (0x152ef0) used a separate Cell and a while-loop with the step at the bottom.

- **C13** For identical sibling return tails, inspect textual return order before sweeping locals. The later return can retain the common code; a short suffix can merge only if encountered first. This explained Fire_Coord (0x4e720) topology; the function remained open in that experiment.

- **C14** If the switch result spills across multiple arms, try breaks into one return after the switch. Hover While_Moving (0xfc0c0) fell from 2,555 to 65 differing bytes; the final slot required the parameter of an inline taking a temporary by const reference.

- **C15** For a named-local count effect, measure the threshold per inlined copy before changing source. A genuine named intermediate can move it. Sidebar Activate (0x2739b0) reached identical bytes; the adjacent Reposition_Sidebar still had a one-byte residue in that experiment.

- **C16** If summands keep exchanging registers, inspect how each value was created. IonBlastClass::AI (0x120880) needed Position.As_Cell() to remove a constructor inline level; eight spellings of the sum had failed.

- **C17** When an out-of-line template member also expands inline earlier, try a non-inline specialization at the end of its TU. Add_Object (0x1689f0) could be emitted there while preserving earlier expansions; moving it up changed Zone_Reset.

- **C18** When two identical COMDAT bodies can occupy an address, use link order, emitting object and caller bindings to determine placement. ZeroRect (0x169ed0) matched the last initializer of one object and the first of its neighbour.

## Victims

- **V1** If independent credible header changes repeatedly break the same claimed function, rematch it under the new header, then run the complete comparison. Zone_Reset (0x14c060) regained its match with the CountryName constructors; the combined set lost no claims over 509 comparisons.

- **V2** For SelectClass::Action (0x2761a0), retain the correct CELL_NONE binding when comparing candidate forms. The old byte match without geoconst includes had the wrong target. Batch 27 recovered a match under the new header.

- **V3** For WinMain (0x283970), compare both headers and inspect first-literal numbering and exception evidence. Its batch-27 form matched with the new header and differed by four bytes under the old one.

- **V4** For Print_CRCs (0x221b90), run the queue probe after each change in its include closure, then verify the wider claim set. Record the position and baseline used for the declaration window.

## Steering policy

- **S1** Kind 1 is permitted with a STEERING label. Record the specific form and the audit result. Example: ScenarioClass’s NoInit constructor (0x252810) uses Lookup_Scenario_String at one of ten sites; the TU retained 68/68.

- **S2** Defer kind 2 to the end phase. Keep unresolved quality work traceable. For comparison, TechnoClass::Rock (0x2cb4b0) is explicitly catalogued as kind 1; the supplied audit identifies no named kind-2 exemplar.

- **S3** Reject kind 3. Keep diagnostic probes out of delivered source. Fire_Coord (0x4e720) illustrates a scratch-only count probe; the sources do not classify that function as a kind-3 submission.

## Dead ends

- **D1** Stop blind mutation beams on a stable one-to-five-byte count or order residue. Search_For_Tiberium_Weighted (0xcb740) stayed two bytes off after roughly 1,000 builds. Inspect header inlines or declaration order when the local neighbourhood is exhausted.

- **D2** When the full declaration sweep is flat, drop the TU-hash hypothesis for that site. Slide_Dialog (0x1dd5e0) produced one variant over 64 counts; inspect the two live values inside the loop instead.

- **D3** Before accepting a one-byte operand explanation, inspect the relocation addends of both loads. Reposition_Sidebar (0x2770d0) had two swapped loads. Further local spelling changes need evidence about their order.

- **D4** When unchanged references disappear before allocation, stop adding weight-only constructs. Look for a real computation or helper-body change. TeamClass::AI (0x2ad120) eventually matched through its inlined callee.

## Where to find more

- **R1** For port selection, start at “Synthesis of the P5 ports”, then “M1: meastes/redalert2-decomp … as a port source”. Worked examples include Repair_Bridge (0x152ef0) and IonBlastClass::AI (0x120880).

- **R2** For allocation, read “KEY: VC6 stack-slot assignment”, “F20: the named-local count lever” and “C2.DLL 8168 rules … evaluation”. Start with Sidebar Activate (0x2739b0) for a measured local-count threshold.

- **R3** For regression review, read “Victim rule confirmed” and “Wrong symbol-map entries can hide wrong source”, then the REMATCH label audit. Zone_Reset (0x14c060) is the confirmed header-rematch example.

- **D5** Recombining near-identical variants does not close a coupled small residue: in batch 50 every variant that fixed one residue byte broke another, because VC6 allocates registers and slots for the whole function. Send_Statistics_Packet (0x28e3f0): 13 variants fix +0x340, all 13 break +0x33a. Use RECOMBINE on larger near misses whose chunks are independent; small coupled residues go to the end phase.

## Community lessons (compare_c1, 26 community-solved cases; detail in compare/SUMMARY.md and compare/annotated/)

- **L1** For the first differing expression, enumerate the real member, conversion and operator overloads in the headers; compile the direct call and the expanded expression separately and compare call targets. Examples: Draw_Extras (0x3aa50) matrix translation getter, Make_Closest (0x219e20) quaternion division, Place_Veins (0x7a900) RNG conversion operator.
- **L2** When the caller bodies agree, compare the direct callees and emitted symbols before editing the caller again; keep a shared-header sibling as a control. Examples: TeamClass::AI (0x2ad120) via TMission_GOTO_SHROUD, Nearing_Target (0xbe390) with FlyTurnLimit::Magnitude_At_Least.
- **L3** Split a live value at a cast, conversion or copy and vary the uses that must survive the call or the next iteration together. Example: IonBlastClass::AI (0x120880), ObjectClass and FootClass pointers.
- **L4** Try the complete donor branch arrangement before scoring single statements (paired split/merge), then remove one change at a time. Examples: Is_Owner_Tested_Control (0x1ded00), TeamClass::AI.
- **L5** Vary a loop as one family: counter direction, derived index, initialisation point and cursor update. Examples: IonBlastClass::One_Time (0x120fd0), CacheBMP (0x281740).
- **L6** Keep three columns of evidence (failed native, donor, delivered native) and test each donor-vs-delivered difference; verify call targets and bindings apart from masked bytes. Examples: Update_Cell_Subzones (0x163130), WaveClass::Load (0x316d90).
- **L7** Ablate both ways: add each hunk to the failed body AND remove it from the passing body. When the answers disagree, keep the hunk for pairwise tests instead of dropping it on the greedy score. Examples: Mech Movement_AI (0x18e7a0), where hunk 9 is neutral alone but costs 853 bytes when removed; Planning_Connect_Selection (0x20f6d0).
- **D6** Micro-calibration can reproduce the exact instruction pattern (Send_Statistics_Packet 0x28e3f0: 4-byte load into EDX, `shr dl,4; and dl,1` in 4 fastcall microtests) while the full TU still schedules a neighbouring push differently. When the expression alone is proven, the residue lives in the full-TU scheduling context: compare the surrounding statements and the arguments of the call, not the expression. Before any header change, measure the include closure (special.h: 158 TUs, 6,618 claims).
- **D7** Anchored source order: for identical-body functions BETWEEN matched flanking symbols, the COFF contribution order predicted 147/147 held-out labels correctly (0 wrong, 50 abstentions; srcorder_s1). Unanchored ranking misassigned 35, so never use it unanchored. A claim still needs one independent binding clue.
- **L8** Port a whole loop from a matched sibling that walks the same structure in another direction (counter, reused neighbour value, exit) and compile that combination before single variants; then ablate it by groups. Subzone_Span (0x161080) matched only with all five groups from Zone_Span's form; one group was neutral alone but cost 13 when removed (batch 60g).
- **L9** For a large window or dialog handler, first map for every case where it ends, which cases share a tail and which return directly; build the shared tail and the file-local helpers together, and compare case entry addresses and jump destinations before statement edits. Static_Proc (0x1eac10): local reordering gained 2 bytes (batch 60), the shared-tail donor form matched 4,512 bytes (batch 60g).
- **L10** When two plausible helper changes each score the same alone, always measure the pair (the fourth cell of the 2x2). Static_Proc: returning the parent record left 1,274, passing the child HWND by const reference left 1,274, both together left 0.
- **L11** A null check per real use versus one shared check changes register choice in every caller of the inlined helper; compile both forms and check the sibling callers. YR Spark/Bounce/Gas via Ballistic_Move; on RA2 Spark it did not close the residue (batch 60g).
- **L12** Verify every call and constructor target by symbol, even at 0 masked differing bytes: Spark_Behavior_AI's constructor call at +0xb1 bound to the wrong symbol while the masked score showed only 3 bytes.
- **W6** Three-way version evidence: workers repeatedly asked for the pristine 1.006 TU (mischa85 checkout) next to our adapted m85 TU and the YR donor. Ship it as context (`m85orig_<tu>.cpp`) for every target whose 1.006 function exists; never adopt it without byte proof.
- **L13** A declaration change that makes several functions exact but breaks exact consumers is a victim-rule case, not a dead end: test per-TU declaration views of the same storage first, then rematch the consumers. Colour masks (0xA5DF30/32/34): split 16-bit red/green masks make DrawMasked (0x282680) and Show_Credits (0xb34d0) exact and regress 7 ownrdraw consumers (batch 61, batch 62 target 1).
- **L14** Compare the ORDERED call sites of both sides before statement work; missing calls point at the inlining or helper boundary. StripClass::Recalc (0x275a60): 11 missing calls found, donor event locals then restored four regions of 979 bytes (batch 61).
- **L15** Residues inside temporaries are often the order in which VC6 inlines their destructors and deallocation; vary the lifetime of each temporary separately. Read_RMG_INI (0x176750): all 97 differing bytes come from temporary-list destructors (batch 61).
- **L16** Splitting a window procedure per message can restore the original frame size and selector table at once. Standard_Dialog_Proc (0x1f77c0): original 40-byte frame, 5 jump targets and 42 selector values exact (batch 61).
- **L17** Coupled donor choices: a direction type, an array check and the operand order of a reverse walk matched only together; each alone made the score worse. Destroy_Bridge2_Near (0x1539b0) matched in batch 61 (see L8/L10).
- **L18** Global data layout is source: whether a global is explicitly initialised (`= 0`) decides its section and spacing, and with it the operands of every consumer. Colour masks: three separate 16-bit globals with explicit `= 0` made DrawMasked (0x282680) exact and kept all 7 ownrdraw consumers (batch 62). Inspect the real definition layout before adding wrappers.
- **L19** Track open near misses next to the claims when a shared declaration changes: the mask fix kept every claim but Control_Proc (open) worsened 3642->3674; record such costs instead of only checking claims.
- **L20** A destructor binding (scalar deleting vs ordinary destructor) is a stronger clue than the hunk score; putting the coupled calls in one small helper reproduced the ordinary destructor. WOL_Buddy_List_Dialog_Proc (0x346940) matched 2816 bytes this way (batch 62).
- **L21** An inlined destructor or helper must be visible in the caller's TU in the form the original had. Show_Credits (0xb34d0) is exact only with EgoClass::~EgoClass/Scroll visible in egos.cpp; our one-definition dedupe removed those bodies (950 bytes then differ). Resolve with a one-definition form (inline in the header or the owning TU), never with duplicate out-of-line definitions.
- **L22** Count-sensitive residues (period 64): Print_CRCs (0x221b90) reload order follows a TU-wide declaration count (calibration pairs 0/64..3/67 identical). Real lifetime moves of existing declarations (Frame read directly, house iterator declared at first traversal) matched it without probes, each alone 4, together 0 (batch 63). Such a match breaks again with the next header change: solve it once under the final header set (deep_p1), not after every change.
- **L23** Move only the definition the caller must SEE: Show_Credits (0xb34d0) became exact when only EgoClass::~EgoClass moved to egos.cpp (claim owner changed with it); Scroll and Render stay with their owner (batch 63).
- **L24** Ownership of a local container is source shape: Scenario_DlgProc (0x1c0a70) matched 1,920 bytes when the caller owns the vector, fills it via a reference and the fallback moves into its case; each change alone left 1,126 or 886 (batch 63).
- **L25** Before replaying a parked patch, classify every edit as already present, applicable once, or divergent, and compile the unmodified tree first. deep_p1 found the whole Print_CRCs header package (techtype Unused2, script Detach, faithful queue forms) already in the tree; our parked notes were stale.
- **V5** Header gate for techtype.h, script.h and queue.h changes: check HouseClass::AI_Build_Defense 0xf0690, Print_CRCs 0x221b90, ScriptTypeClass::Detach 0x260150, WinMain 0x283970 and both TechnoTypeClass constructors 0x2cf0b0/0x2cfc50 first, then the full closure. Print_CRCs survives removed declarations in queue.h but loses 4 bytes when real declarations are added (deep_p1 robustness test).
- **L26** Qualify inherited calls explicitly when the original binds them statically: StripClass::Recalc (0x275a60) gained 65 bytes from `GadgetClass::Disable()` on both calls (batch 64).
- **L27** When an inlined helper must stay inline, give the caller a local copy of its input instead of restructuring the helper: Read_Text_File (0x2ee430) went 240 -> 6 with a first-character temporary plus a target-local copy for Collapse_White_Space; the 6 left are one scheduling swap (batch 64).
- **L28** A local gain that breaks a frozen gate is not a gain: freeze the stack frame, prefix and known-exact ranges before accepting a lower total (Tactical::Render, Projectile_Motion named double: 40 bytes locally, 51 -> 1,281 in total; batch 64).
- **L29** Identify a community function by its resource and callback, not by size, before porting: RA2's caller dispatches the lobby (resource 0x113) and the buddy list (0x116) separately; gibbo's YR Join_WOL_Lobby is our Run_Online_Menu (0x3474e0), 223 -> 25 with the donor retry, shared destructor, independent event stores and channel-leave expansion (batch 64g).
- **V6** Compare EVERY emitted function of the TU (raw COFF bytes and relocation targets) for finalists, not only the named controls: a 25-byte Run_Online_Menu candidate silently changed four bytes in OnGameStart (batch 64g).
- **V7** Put the emitted SYMBOL SET (template instances, constructors, members) into every search gate next to the named controls: a List_Proc candidate passed all six controls but dropped a vector growth member and changed Trackbar_Proc; a Run_Online_Menu local class reached 8 bytes but added a constructor (batch 65).
- **L30** Validate an annotated community address against the enclosing native function and a proven caller before porting: both annotated addresses for gibbo's FUN_00793D20 (Start_Talking_To family) fell inside existing event handlers, so no twin was claimed; their WOL_Main_Dialog_Proc twin (resource 0x113) is our already matched 0x33A680 (batch 65g).
- **L31** Before porting a community twin, check the claim list by RVA, not only by name: gibbo's FUN_0046DFD0 is our 0x65bf0, already claimed as CampaignScoreClass::Dialog_Proc in src/ra2/CampScor.cpp; the m85 campscor.cpp Campaign_Score_Dialog_Proc is a duplicate definition of the same function (one-definition rule 10). Also: a near port that reads an uninitialised high half is not a candidate (Random_Cell_In_Zone, batch 66g).
- **V8** ORDER_PLACED claims (user 2026-11-25): identical empty bodies placed only by anchored source order (D7) may be claimed with `"evidence"` = identical body, placed by source order, and are listed in metadata/level2_order_placed.json. Watch for an independent clue (a call from a matched function, a vtable slot, a function-pointer table) and promote or correct the name; never count them as name-proven.
- **W7** VC6 launch on the station (user 2026-11-25: the popups only say MSPDB60.DLL cannot be found, so the working directory or PATH is wrong): start cl.exe/link.exe by absolute path, working directory = job folder, PATH beginning with the folder holding MSPDB60.DLL (Common/MSDev98/Bin) and VC98/Bin, and set the parent error mode to 0x8003 (SEM_FAILCRITICALERRORS|SEM_NOGPFAULTERRORBOX|SEM_NOOPENFILEERRORBOX) so a missing DLL returns an exit code instead of a dialog. Now part of every batch TASK (aistation_batch.py).
- **L32** Before taking hunks from a community twin, make a small version-feature inventory: every donor-only dispatch case, dialog exception, field, side effect or callee with its native site, mapped in both directions (operations can move between branches or have no counterpart; keep an explicit "unmapped"). Admit a donor slice only after accounting for everything it removes or imports. Fire_At's occupant-index update moves between contexts; gibbo's Join_WOL_Lobby is not our Run_Online_Menu twin (its 223->25 came from the 1.006 source) (compare_c2).
- **V9** For anchored blocks report two distances: at the original RVA and relative to the block's own entry in each image, plus the resolved call and table destinations. A block can be internally exact but displaced (Static_Proc move/size block: 47 at the fixed position, 0 internally), and masked switch data can look exact while two destinations differ (Random_Cell_In_Zone) (compare_c2).
- **W8** On the first VC6 loader fault in a batch, stop all further dispatch; run one isolated smoke build before admitting parallel builds, after checking that the worker kit's DLLs equal the shared reference (149 MSPDB60.DLL popups were logged on 2026-11-25 before this rule) (compare_c2). Mention the guard only when a fault occurs, not when it passes (user 2026-11-25). The 2026-11-25 popups (last 14:55) are closed history: do not investigate them or the event log again, and never block compiler starts because of them.
- **L33** Persist on one function and keep a WITNESS per region (per switch arm or block): the best local source form even when it loses the global score, then combine witnesses explicitly. SuperClass::Place (0x292ef0) went 78 -> 69 -> 33 -> 3 -> 0 over about 2,100 builds in twelve families in a focused job, after batches 72-79 had plateaued because their greedy searches kept only the global best and their declaration family generated the same code (collect_c2 WHY_IT_WORKED).
- **L34** An assembly-scheduling route is NOT a C++ match: Set_Map_Dimensions (0x145970) reached 0 only by editing the VC6 listing (schedule.py); its best pure C++ is 148 bytes. Treat such results as matched-asm (end-phase fallback, reported separately) and keep the C++ near miss as the source.
- **V10** Helpers must not add declarations to shared headers (class members in cell.h, unit.h, infantry.h, ...): every such declaration shifts Print_CRCs and WinMain (V5). Put helpers as file-local static or inline functions in the TU itself. Set_Map_Dimensions' 54-byte form needed CellClass::Restore_From in cell.h and lost Print_CRCs + WinMain (deep m1).
- **V11** Integration review must reject kind-3 tricks before accepting a source: grep the delivered TU for `*(volatile`, `(volatile ...*)&`, `__asm`, `_asm` and `#pragma` changes. The collect_c2 Map form (148 bytes) contained `*(volatile int*)&cellcount = 0;` and was integrated by mistake on 2026-11-26; reverted the same day (deep m1b found it).
- **L35** Follow one displacement through every definition and consumer: four Spark disagreements (+0x123, +0x167, +0x16c, +0x204) wanted the same stack slot; moving only the real obstruction scalar to caller ownership fixed all four. Keep the value that must survive a virtual call alive in the source (a conditional that carries the prior result), and use community behaviour clues (gibbo's per-test checks) to choose WHICH expression to vary. Spark_Behavior_AI (0x201120) matched with a four-factor combination; only the complete subset of 16 matched (deep s1).
- **L36** Treat adjacent bitfield writes as one register-allocation unit: word-masked bit 14, a named assignment for bit 15 and a word-masked bit 16 cut Set_Map_Dimensions' restore window from 108 to 36 (deep m1). Check the direct-call list after every aliasing or numbering experiment (live aliases added a TPoint3D constructor call).
- **W9** Reproduce the actually submitted file first and record each edit's direction and whether it is deliverable: Map's submitted source scored 581, an archived variant 148, and the 148 relied on a volatile workaround (V11) (deep m1, m1b).
- **L37** Which member computes an identical expression matters to VC6's argument reservation: velocity.Magnitude() vs Speed() or a free helper moved the sqrt argument reservation by 38 bytes. A non-owning, file-local view struct with its own Magnitude() recovers the original placement without a shared declaration. Projectile_Motion (0x190670) matched by joining two disjoint witnesses (13-byte and 38-byte) (deep p1, gibbo YR form as lead).
- **V12** Recover TU-local constant addresses from the module's own initialization chain: three nominal registry addresses of Projectile_Motion's constants belonged to other modules' copies (see the per-TU binding C-item).
- **L38** Naming a value just before its use moves its load (Do_MISSION_MISSILE: the warhead load moved from 0x487d3 to 0x487be, 10 -> 35 bytes); a calibration of 64 declaration counts left the residue unchanged, so it is not count-type. Test scheduler hypotheses on already-matched functions with the same shape first (deep d1).
- **L39** When a clean community build of the OTHER version shows the same residue against our original (Spread_Units_Around_Cell: meastes 1.006 built with its own headers matched all 80 relocations and left the same 4 bytes vs 1.001), the residue is probably a real 1.001 source difference; look for 1.001-specific statements, not compiler tricks (deep u1). Count probes (101 local counts, 65 first-declaration counts) left the target unchanged while Print_CRCs moved 0-16: not count-type.
- **L40** A one-byte witness can expose a common cause: WM_ERASEBKGND and LB_GETCURSEL in List_Proc differ only in the epilogue frame immediate (0x34 vs native 0x2c), i.e. 8 bytes of locals too many; cross independent handler placements (LB_SETCURSEL -445 bytes; WM_VSCROLL only helps after it) (deep l1).
- **L41** Subtract pending pushes before naming an original stack slot: `mov [esp+0x1c],eax` with `push 0xa0` already on the stack is slot 0x18. Map our slots with a `/FAs` listing (named locals and `$T` temporaries) aligned to the original's instruction stream; it names the variable in the wrong slot (Claude exit1, `slots.py`).
- **L42** A count-type residue can be function-wide and position-independent. Use K dead probes only as a gauge, then grid-search natural community forms for the same state at K=0; re-gauge every structural candidate over K before rejecting it (Exit_Object: block-local `nearby` looked worse at K=0, decisive over K) (Claude exit1).
- **L43** Arm order decides which merged tail VC6 keeps: writing the clone arm first moved the shared `ScenarioInit--; return 2` tail to the original's place, while the vehicle arm is still emitted first. `if (c) f(&Map[cell]); else f(NULL);` cross-jumps differently from a ternary argument (Claude exit1).
- **L44** A Cell reused across switch cases (address taken) gets a whole-function memory slot; block-local Cells share one slot with sibling blocks. A temporary bound to a const reference advances a TU-wide counter that renames `$S`/`$E` statics in other functions (bytes equal, symbol names differ) (Claude exit1).
- **L45** Reusing one variable for two roles is source shape: Plot_Line reuses `dx` as the Bresenham error term (`int span = dx; dx = 2 * dy; int dy2 = dx;`). VC6 builds one register web per variable object, so the reuse joins live ranges and decides register and dead-argument-slot choice; a separate `delta` cost 76-172 bytes. Port a matched same-version twin whole-branch before any search: batch 37 spent about 1,100 grid rows reaching 132 bytes, the gibbo body matched on the first compile (Claude plot1).
- **L46** Near-equal record names can be placeholders: 0x35f840 was listed as `?Slot17@XSurface@@UAE_NXZ` but is Plot_Line (fastcall callback `P6IXABV3@@Z` under -Gr). Take the mangled name from our compile at that RVA (Claude plot1).
